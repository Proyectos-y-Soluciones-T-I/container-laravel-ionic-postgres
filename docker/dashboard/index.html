Contenido de .env


          
Copiá este contenido en .env en la raíz del repo. Nunca lo subas a git.

        

      


      
      

        Los valores se cargan desde el filesystem del repo a través del entrypoint. Editá los campos y descargá el archivo generado.
      

      

      

    


    
    

      
Cómo configurar el entorno

      


        

          
            
              1
              Clonar el repo y crear los archivos .env
            
            
          
          

            
git clone <repo-url>
cd container-laravel-ionic-postgres
cp .env.example .env
cp envs/ayudando.env.example envs/ayudando.env
cp envs/emergencias.env.example envs/emergencias.env
cp envs/fiscalizacion.env.example envs/fiscalizacion.env

            
Editá cada archivo y completá los valores marcados con change_me:

            
    
              
  • .env — POSTGRES_PASSWORD, PGADMIN_PASSWORD
    • 
              
  • envs/<proyecto>.env — APP_KEY, JWT_SECRET, credenciales SMTP
    • 
              
  • APP_KEY — generá con el paso 4
    • 
            

          

        


        

          
            
              2
              Levantar infraestructura compartida
            
            
          
          

            
Hacelo una sola vez. Incluye postgres, pgAdmin y este dashboard.

            
docker compose -f docker-compose.shared.yml up -d

            
docker compose -f docker-compose.shared.yml ps

          

        


        

          
            
              3
              Levantar un proyecto específico
            
            
          
          

            
Solo uno a la vez. Levantá el shared primero.

            
docker compose -f docker-compose.ayudando.yml --project-name ayudando up -d
# ó
docker compose -f docker-compose.emergencias.yml --project-name emergencias up -d
# ó
docker compose -f docker-compose.fiscalizacion.yml --project-name fiscalizacion up -d

          

        


        

          
            
              4
              Generar APP_KEY y migrar la base de datos
            
            
          
          

            
docker exec ayudando_backend php artisan key:generate
docker exec ayudando_backend php artisan migrate
# ó importar dump existente:
docker exec -i shared_postgres pg_restore -U postgres -d ayudando --no-owner --no-acl < src/ayudando/ayudando.tar

          

        


        

          
            
              5
              Conectar pgAdmin al servidor de base de datos
            
            
          
          

            

              
Hostpostgres(nombre del servicio, NO localhost)

              
Port5432

              
Usernamepostgres

              
Maintenance DBpostgres

              
Passwordvalor de POSTGRES_PASSWORD

            

          

        


        

          
            
              !
              Problemas frecuentes
            
            
          
          

            

              
Backend no conecta a la DB

              
Verificá que shared_postgres esté healthy. Causa más común: POSTGRES_PASSWORD vacío.

              
docker compose -f docker-compose.shared.yml ps

            

            

              
Frontend no detecta cambios

              
docker compose -f docker-compose.ayudando.yml --project-name ayudando restart frontend

            

            

              
Conflicto de puertos

              
Sobreescribí en el .env:

              
AYUDANDO_NGINX_PORT=8083
AYUDANDO_FRONTEND_PORT=4203

            

            

              
Reset total de la DB

              
# ⚠️ Destruye todos los volúmenes
docker compose -f docker-compose.shared.yml down -v
docker compose -f docker-compose.shared.yml up -d
docker exec -i shared_postgres pg_restore -U postgres -d ayudando --no-owner --no-acl < src/ayudando/ayudando.tar
