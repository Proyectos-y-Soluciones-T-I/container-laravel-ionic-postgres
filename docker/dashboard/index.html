Cómo configurar el entorno

1 Clonar el repo y crear el .env 
git clone <repo-url>
cd container-laravel-ionic-postgres
cp .env.example .env

Editá .env y completá las variables marcadas con change_me:

  • POSTGRES_PASSWORD — contraseña del servidor de base de datos
  • PGADMIN_PASSWORD — acceso a pgAdmin
  • *_APP_KEY — generá con el paso 4
  • *_JWT_SECRET — string aleatorio largo por proyecto
  • *_MAIL_HOST/USERNAME/PASSWORD — credenciales SMTP por proyecto
2 Levantar infraestructura compartida

Hacelo una sola vez. Incluye postgres, pgAdmin y este dashboard.

docker compose -f docker-compose.shared.yml up -d
docker compose -f docker-compose.shared.yml ps
3 Levantar un proyecto específico

Solo uno a la vez. Levantá el shared primero.

make up PROJECT=ayudando
# ó
make up PROJECT=emergencias
# ó
make up PROJECT=fiscalizacion
4 Generar APP_KEY y migrar la base de datos 
make artisan cmd="key:generate" PROJECT=ayudando
make migrate PROJECT=ayudando
# ó importar dump existente:
make db-import PROJECT=ayudando
5 Conectar pgAdmin al servidor de base de datos
Hostpostgres(nombre del servicio, NO localhost)
Port5432

Maintenance DBpostgres
Passwordvalor de POSTGRES_PASSWORD
! Problemas frecuentes

Backend no conecta a la DB

Verificá que shared_postgres esté healthy. Causa más común: POSTGRES_PASSWORD vacío.

docker compose -f docker-compose.shared.yml ps

Frontend no detecta cambios

make restart PROJECT=ayudando

Conflicto de puertos

Sobreescribí en el .env:

AYUDANDO_NGINX_PORT=8083
AYUDANDO_FRONTEND_PORT=4203

Reset total de la DB

# ⚠️ Destruye todos los volúmenes
docker compose -f docker-compose.shared.yml down -v
docker compose -f docker-compose.shared.yml up -d
make db-import PROJECT=ayudando
